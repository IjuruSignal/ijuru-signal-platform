# Production prompt

Build Ijuru Signal, a Rwanda-focused product for climate evidence and field verification, as an independent Next.js and TypeScript project. Read PRODUCT.md, DESIGN.md and the project research first. Verify competition requirements and provider terms with current primary sources. Treat names, partners and impact as unverified until evidenced.

Implement the narrow MVP in [02-product.md](02-product.md) and the bounded integration workflow in [03-architecture.md](03-architecture.md). Use a dedicated PostgreSQL database, private storage where necessary, source-owned shadcn-style components and an independently deployable worker only when required. Do not introduce a monorepo or a shared cross-project dependency.

Follow the impeccable skill for UI work. Preserve this product's own design language, build responsive and accessible flows, handle missing inputs, failures and uncertainty, and test with representative users. Expose evidence sources and freshness; keep human judgment in the loop. Document setup, environment variables, tests, costs, permissions, risks and what remains unimplemented. Never invent deployment, partners, performance or outcomes.
